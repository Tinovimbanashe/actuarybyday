EcoTravel AI is a generative‑AI–powered chatbot designed to help users make more environmentally responsible travel decisions. Built as part of an AI lab project, the bot uses a large language model to answer questions about sustainable tourism, eco‑friendly transportation, responsible travel habits, and ways to minimize environmental impact. It offers recommendations such as choosing greener transportation, reducing waste, supporting local businesses, and selecting eco‑friendly accommodations, all aimed at promoting sustainability‑focused travel behavior.

Important Lessons Learned

The project highlighted several key insights: Prompt quality matters. More precise prompts yielded clearer, more relevant sustainability guidance, while vague prompts led to overly general responses.

AI can effectively structure and simplify complex environmental concepts, making sustainability more accessible to users.

Design thinking is useful in AI development. Applying the Empathize‑Define‑Ideate‑Prototype‑Test framework helped ensure the bot addressed real user challenges in sustainable travel.

Generative AI is a practical tool for real‑world issues. This project demonstrated how AI can support environmental awareness and help users make more informed travel decisions.

If you are an actuary, then all those (pesky) exams we take will actually assist in your understanding of AI. I am going to cover two main topics in AI, machine learning which should be familiar to you, and deep learning, which the main component of AI causing all the hype. 

Machine Learning (ML). (You can probably skip this part).
 
Machine Learning (ML) is a subset of Artificial Intelligence (AI) that focuses on using historical data to build algorithms capable of learning patterns from data and making predictions or decisions on new unseen data, without being explicitly programmed for each task. 

Machine learning (ML) is what you did when you took exams Statistics for Risk Modelling (SRM) and Predictive Analytics (PA) for people taking exams through the Society of Actuaries (SOA) and exams Modern Actuarial Statistics 1 and 2 for people taking exams through Casual Actuarial Society (CAS). (I'm doing the SOA track.) I won't spend much time on this, because I know you know what this is. Here is the brief recap.

The main types of ML are supervised learning, unsupervised learning and reinforcement learning. The first two might be very familiar. That is, supervised learning uses structured data to train algorithms such as regression models including as linear models and generalised linear models and makes predictions by minimising a loss function. Regression also includes decision trees and time series. Unsupervised learning includes clustering and principal components analysis (PCA). Unsupervised learning works with unlabeled data to find patterns or clusters, and in the case of PCA can be used for dimension reduction. (Remember when you learnt how to calculate the principal component score. Ahh so many sleepless nights.) 

Reinforcement learning was unfamiliar to me prior to my machine learning fundamentals (AIML - 500) class. From my class notes: "Reinforcement learning involves an agent that learns by interacting with an environment and receiving feedback in the form of rewards or penalties. The goal is to maximize the cumulative reward."

From the article Mastering RL in Statistical Machine Learning I got the information below.
"States, Actions, and Rewards
A Markov Decision Process (MDP) provides a mathematical model to describe an environment in which decisions are made over time and is typically defined by:
a) States ( S): The set of all possible configurations in which the environment can exist.
b) Actions ( A): The set of all actions an agent can take.
c) Rewards (R): The immediate feedback received after taking an action in a given state."

An RL agent is a conceptual entity, but in practice it must be implemented with algorithms. 

Now, for the fun part, deep learning (DL): 

Deep Learning (DL)

Deep learning is a subset of machine learning that uses multi-layered artificial neural networks to learn complex patterns from large datasets. Inspired by the human brain, these models automatically extract features from raw data, enabling end-to-end learning without manual feature engineering.

Neural networks: Layers of interconnected nodes (called neurons) that process data and learn patterns through training. It is basically a collection of equations. 

Neurons: Each node receives input, applies a mathematical function, and passes output to the next layer. Each neuron does something like: 𝑦 = 𝑓 ( 𝑤 ⋅ 𝑥 + 𝑏 ).
Where:
 𝑥 = inputs
𝑤 = weights
𝑏 = bias
𝑓 = activation function

Stack a lot of these together → you get a neural network.
So: The network itself = a big mathematical function

Weights and biases: Each connection/node has a weight that adjusts during learning to improve accuracy.

Activation functions: Decide whether a neuron should "fire" based on its input (e.g., ReLU, sigmoid).

Deep Learning Algorithms: 
The network doesn't magically know good weights — it needs an algorithm to learn them. Example algorithms include. 

Gradient Descent: moves weights to reduce error.
Backpropagation: Computes gradients efficiently using the chain rule. It works with gradient descent to update weight.

Model Architectures (Structure of a Neural Network)

Model architectures define the structure and layout of a neural network. They describe how many layers there are, how those layers are connected, what each layer does and how information flows.  
Common architectures include Convolutional Neural Network (CNN) used for image recognition and Recurrent Neural Network (RNN) used in natural language processing. 

An example of an architecture using CNN
CNNs learn visual patterns step by step, from simple → complex.
Example:
Layer 1 → detects edges.
Layer 2 → detects shapes.
Layer 3 → detects objects

Architectures design the shape of the math; neural networks are the math itself.

Big Picture
Deep learning = Neural Network (equations) + Training Algorithm (how it learns) + Architecture (how it's structured).

Model Equation Approximation

Deep learning models, such as neural networks, are often described as "black boxes" because they do not output explicit, human-readable equations for their decisions. Instead, they represent knowledge across millions of parameters spread over multiple non-linear layers. Despite this complexity, engineers and researchers have developed several methodologies to infer or approximate the rationale behind a model's output. These methods do not require the model to explicitly produce an equation, but rather analyze its behavior, intermediate computations, or sensitivity to inputs.
